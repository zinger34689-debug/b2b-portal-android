B2B PORTAL — ANDROID APK

Это исходный Android-проект для сборки установочного APK через GitHub Actions.
В текущей среде нет Android SDK/Build Tools, поэтому готовый APK здесь не собран.

КАК ПОЛУЧИТЬ APK БЕЗ УСТАНОВКИ ANDROID STUDIO:
1. Создай новый пустой репозиторий GitHub (например, b2b-portal-android).
2. Распакуй содержимое этого архива и загрузи ВСЕ файлы проекта в корень репозитория.
3. Открой вкладку Actions в репозитории.
4. Выбери workflow «Build Android APK» и нажми Run workflow.
5. После завершения открой успешный запуск, внизу раздел Artifacts.
6. Скачай B2B-Portal-APK.zip, распакуй его — внутри будет app-debug.apk.
7. Передай APK на Android, открой файл и разреши установку из этого источника, если Android спросит.

ПРИМЕЧАНИЯ:
- Это тестовая debug-сборка, подписанная автоматически тестовым ключом Android Gradle Plugin.
- Для последующих обновлений приложение должно быть подписано тем же ключом; для постоянного распространения нужна отдельная release-подпись.
- Приложение открывает текущий адрес Cloudflare Worker. После подключения b2b-portal.ru адрес можно заменить в MainActivity.java и пересобрать APK.
- Портал доступен по публичной ссылке; не размещай там конфиденциальные данные, если доступ не ограничен.
